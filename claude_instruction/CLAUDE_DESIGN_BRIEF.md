# CLAUDE DESIGN BRIEF

# PROJECT

Build a premium engineering portfolio.

This is NOT a resume website.

This is NOT a project gallery.

This is NOT a collection of screenshots.

The website should feel like an interactive documentary about engineering.

The user should feel like they are scrolling through a Netflix documentary or Apple product launch.

Every section should reveal a story.

Every animation should support the narrative.

The portfolio should communicate:

* Technical depth
* Product thinking
* Systems thinking
* Engineering leadership
* Problem solving

Target audience:

* FAANG Recruiters
* Engineering Managers
* Senior Engineers
* Technical Leads

---

# DESIGN INSPIRATION

Visual references:

* Apple Product Pages
* Stripe
* Linear
* Vercel
* Raycast

Avoid:

* Dribbble portfolios
* Generic agency websites
* Screenshot galleries
* Masonry layouts
* Behance project pages

---

# VISUAL LANGUAGE

Typography first.

Motion second.

Screenshots third.

The portfolio should rely primarily on:

* Typography
* Space
* Motion
* Storytelling

Not screenshots.

Not cards.

Not colorful illustrations.

---

# DESIGN PRINCIPLES

Rule 1

One idea per screen.

Never show multiple competing elements.

---

Rule 2

One screenshot focus at a time.

Never show galleries.

Never show grids.

Never show multiple phones together.

---

Rule 3

Every chapter begins with tension.

Every chapter ends with resolution.

---

Rule 4

The engineering problem is the hero.

The company is supporting evidence.

---

Rule 5

Animations must explain concepts.

Never animate for decoration.
